# 观域 Voyant

把屏幕上任意区域框成"监视框"，画面一变化自动唤起 AI 视觉决策；AI 使用鼠标键盘工具直接操作框内内容，重要信息自动存成 markdown 记忆。不绑定任何软件——微信、网页、桌面程序都可以盯、都可以操作。

单文件 Python 后端（约 2000 行，无框架）+ 原生 HTML 前端（无构建），Windows 本地运行，数据全部留在自己电脑上。

---

## 功能特性

- **多监视框**：框选屏幕任意区域，或直接选择一个窗口（窗口移动/重启自动跟随、句柄失效按标题自动重绑），每秒截图、预览实时。
- **画面变化唤起 AI**：变化度超阈值 + 连续两拍确认 + 冷却时间，防误触；监控与聊天共用同一个会话，你在聊天里交代的规则 AI 监控时也会遵守。
- **绿格定位 + 先瞄后打**：截图叠加绿色 10×10 定位格；大目标一步点击，小图标先"瞄准"（只填 row/col）看格子放大图、按刻度读准 ox/oy 再点，专治点不准。
- **文字点名点击**：click_text 用 Windows 自带本地 OCR（离线、毫秒级）按文字直接点击，带文字的目标点名即中。
- **17 个工具**：点击/双击/右键/拖拽/滚动/打字/按键/清空/读焦点/OCR 读屏/AI 读屏/等待/记忆四件套……每个工具的详细使用说明随工具定义自动注入给模型。
- **markdown 记忆库**：按主题文件夹分类保存原文，搜索/列出/读取，AI 自己决定存什么、去哪找。
- **会话管理**：多会话、新建、改名、删除（真删）、上下文超预算自动压缩成滚动摘要；会话存储位置可改，旧文件自动迁移。
- **模型可换**：首页「设置」弹窗改模型名/接口地址/密钥，带「测试连接」；任何 OpenAI 兼容接口都能接。
- **思考过程实时流式**：会话页实时滚动显示模型思考（stream）。
- **安全护栏**：演练模式（只记录不动鼠标）、焦点护栏（焦点不在框内拒绝打字）、暂停硬闩（中断在途请求并禁止一切唤醒）、命中窗口回执（点偏了能看出来）。

## 快速开始

### 1. 环境要求

- Windows 10/11
- Python 3.10+（开发用 3.12），路径或 PATH 均可
- 一个 OpenAI 兼容的视觉模型 API Key（默认对接智谱 `glm-5.3-flash`）

### 2. 安装依赖

```
pip install pillow pywin32 openai pyperclip winrt-runtime winrt-Windows.Media.Ocr winrt-Windows.Globalization winrt-Windows.Graphics.Imaging winrt-Windows.Storage.Streams
```

（winrt 系列是本地 OCR，建议用国内镜像装。）

### 3. 配置

复制 `config.example.json` 为 `config.json`，填入你的 `api_key` 即可，其余字段都有默认值。

### 4. 启动

双击 `start.bat`，浏览器自动打开 `http://127.0.0.1:8770`。
（或手动：`python bot.py`；不想自动开浏览器先 `set NO_BROWSER=1`。）

## 界面与使用指南

### 左侧：监视框

- **框选屏幕区域**：在屏幕上拖一个矩形；**选择窗口**：从列表里挑一个窗口。
- 每个框实时预览、可开关"变化监控"；「看一眼」让 AI 描述当前画面。
- 框内内容要可见、不被遮挡（程序截的是屏幕像素，被挡住 AI 就看不见）。

### 会话页

- 控制开关：自动执行（画面变化是否唤起 AI）、演练模式（所有屏幕操作只回执不执行，测试必开）、暂停 AI（硬闩：立刻中断当前调用，暂停期间任何变化都不再唤醒）。
- 会话：下拉切换、新建、**改名**、删除（真删，谨慎）。会话存储位置在「记忆」页可改。
- AI 思考过程实时滚动显示。
- 执行过程：AI 每一步（触发/思考/工具/结论/异常）一目了然。

### 大脑页

- 系统提示词：AI 的人格与工作规则，可自由修改。
- 参数：单次步数上限、变化灵敏度、触发冷却、检查间隔、上下文预算、思考深度（关=快速执行）。
- 工具开关：每个工具可单独启停，点「使用说明」可看该工具的完整用法（AI 实际收到的就是这份说明）。

### 记忆页

- 记忆文件夹位置可改；文件夹树 + 查看/编辑/删除记忆文件；可直接打开文件夹。
- 会话存储位置：聊天记录 `history.json` 的存放目录，保存后当前会话立即写入新位置，旧文件保留作备份。

### 模型设置（左上角「设置」）

- 改模型名称 / 接口地址 / API 密钥（密钥掩码显示，留空=不修改），带「测试连接」。
- 换服务商时接口地址和密钥要一起换；保存立即生效。

### 结束进程（右上角）

- 红色按钮，弹窗确认后程序先落盘会话再退出。

### 一次典型的点击（先瞄后打）

1. 大按钮/文字目标：AI 直接给 row/col/ox/oy 一步点击；
2. 小图标：AI 先只填 row/col → 程序回传该格放大图（横轴=ox、纵轴=oy 的刻度图）→ AI 读准偏移后填全参数真正点击；
3. 带文字的目标优先 click_text 按文字点名。

绿格规则：绿色 10×10 网格不标数字，row 从上往下数 1~10、col 从左往右数 1~10；目标压线时归邻格并把偏移补到 0/100；贴边时对应 row1/col1/row10/col10。

## 配置字段（config.json）

| 字段 | 说明 |
|---|---|
| api_key | 模型密钥（必填） |
| base_url | OpenAI 兼容接口地址 |
| model | 模型名（需支持视觉） |
| system_prompt | 系统提示词 |
| memory_dir | 记忆库文件夹 |
| history_dir | 会话记录文件夹（history.json 所在目录） |
| boxes | 监视框列表（程序自动维护） |
| auto_run | 画面变化自动唤起 AI |
| dry_run | 演练模式 |
| check_interval / change_threshold / trigger_cooldown | 监控节奏 |
| max_steps | 单次任务步数上限 |
| context_budget / compress_keep_recent | 上下文压缩 |
| thinking | enabled / disabled / auto |
| active_session | 当前会话 |
| tools | 各工具开关 |
| web_port | 服务端口（默认 8770） |

> config.json 含密钥，已被 .gitignore 排除，永远不会上传。

## 工作原理（一分钟版）

每秒对所有监视框截图并与上一帧比对；变化超阈值且不在冷却/暂停时，把带绿色定位格的截图连同触发说明发给视觉模型；模型按工具定义选择工具（一轮至多一个屏幕动作，做完立刻附新截图核对），循环直到给出结论。坐标用"格号+格内偏移"两级定位，程序换算成物理像素执行；点击瞬间自动抓落点放大图供模型核对修正。聊天、监控、"看一眼"走同一个会话，上下文超预算自动压缩。

## 常见问题

- **端口被占**：8770 被旧进程占用时程序会直接报错退出，关掉旧命令行窗口再启动。
- **点不准小图标**：这是视觉模型的正常现象，工具已内置"先瞄后打"；也可在提示词里引导 AI 优先用 click_text。
- **OCR 不识别**：确认系统装了中文语言包（设置→时间和语言→语言）。
- **微信窗口被挡**：监视框截的是屏幕像素，被其他窗口遮住的部分 AI 看不见。
- **换模型**：首页「设置」里改，注意视觉能力（要能看图）。
- **删除会话/记忆**：会话删除是真删；记忆文件删除前会确认。

## 隐私与安全

截图、会话、记忆全部存在本地 `data/` 目录；只有调用模型 API 时才会把监视框截图发送给你配置的模型服务商。`config.json`（含密钥）与 `data/` 均已排除在版本库之外。
